# BPS Insight Hub

Create a HIGH-FIDELITY FRONTEND-ONLY PROTOTYPE for:

# BPS AI ASSISTANT

### AI Work Assistant for BPS Employees

IMPORTANT:

This project is ONLY a UI/UX prototype.

DO NOT build a real backend.

DO NOT build a database.

DO NOT connect to external APIs.

DO NOT connect to real BPS APIs.

DO NOT implement real authentication.

DO NOT implement real LLM/AI integration.

DO NOT implement real RAG.

DO NOT implement real file processing.

DO NOT implement real data persistence.

Everything should use MOCK DATA and FRONTEND INTERACTIONS ONLY.

The goal is to create a convincing, polished prototype that demonstrates how the future BPS AI Assistant could work.

==================================================

1. PRODUCT CONCEPT

==================================================

BPS AI Assistant is a conceptual AI-powered workspace designed for employees of Badan Pusat Statistik (BPS) Indonesia.

The application helps employees:

- search statistical datasets

- ask questions about data

- analyze datasets

- understand documents

- generate visualizations

- discover statistical insights

- generate executive briefs

The product should NOT look like a generic chatbot.

It should feel like:

BPS + Enterprise AI + Statistical Data Platform.
